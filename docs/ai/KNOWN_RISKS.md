# 已知风险登记

状态以本文件为准；编码和上线过程中持续更新，不以口头承诺关闭风险。

## R-001 Tauri 打印能力

- 状态：开放，编码前验证
- 影响：A4 销售单、58/80mm 小票或标签可能分页、中文字体、静默打印不可靠。
- 验证：使用真实 Windows 版本、打印机、纸张和中文模板做 PoC；覆盖份数、边距、失败重试、防重复正式单。
- 退出方案：保留 React UI 和服务端，Windows 外壳切换 Electron；不要牺牲现场打印可靠性。

## R-002 门店网络稳定性

- 状态：开放，阶段 0 连续采样 7 天
- 影响：云端主账不可达时不能正式过账。
- 控制：缓存查询、离线草稿、清晰网络状态和幂等重试。
- 退出方案：若实测无法支撑日常营业，切换店内局域网主账 + 异地备份/受控远程入口。

## R-003 扫码与标签设备

- 状态：开放，现场验证
- 影响：扫码结束符、焦点、码制、弱光/破损标签和连续扫码差异造成错品。
- 验证：Windows USB 扫码枪和 Android 相机实机覆盖 EAN-13、Code 128、QR 及异常权限。

## R-004 现有数据质量

- 状态：开放，等待样本
- 影响：重复条码、混乱单位、同名商品、库存/欠款不平会污染新账。
- 控制：模板预校验、重复报告、两轮试迁移、期初平衡检查、上线签字锁定。

## R-005 会计与税务边界

- 状态：开放，需经营者与代账/会计确认
- 影响：经营子账被误认为满足法定会计、税务申报或电子档案全部要求。
- 控制：首版明确只做经营管理；需要替代法定会计软件时另立合规阶段，由专业会计逐条验收法规与数据标准。

## R-006 多单位与成本口径

- 状态：开放，需真实商品样例
- 影响：箱/包/个拆零与整机实际成本处理不当，导致库存和毛利失真。
- 控制：使用精确单位换算；首版普通商品移动加权平均，整机序列号实际成本作为可选扩展；上线后不可无痕切换。

## R-007 移动端分发

- 状态：开放
- 影响：Android 签名/更新、iOS 设备与开发者账号条件可能影响交付。
- 控制：首期 Windows + Android 优先；阶段 0 明确是否必须 iPhone，并登记签名密钥所有权和恢复方式。

## R-008 单人维护连续性

- 状态：持续
- 影响：关键知识、账号和恢复能力集中于一个开发者。
- 控制：保持 ADR、自动测试、可复现环境、资产清单、恢复演练和交接验收；AI 产出接受同一质量门禁。
