# ADR-0003：销售错单采用独立整单冲销

- 状态：已接受
- 日期：2026-08-31

## 背景

已过账销售会同时影响库存、成本、资金或客户欠款。直接删除或修改原单会破坏审计链，也可能造成库存、资金和往来账不一致。销售退货表示客户现实中退回商品，不能用于掩盖重复开单、客户选错或商品录错等错误业务事实。

## 决策

1. 销售错单使用独立 `SalesReversal` 与明细记录，引用唯一原销售单；原单保留并改为 `REVERSED`，禁止物理删除。
2. 冲销必须在一个 Serializable 事务内完成：整单按原销售成本回原仓、追加正向库存流水、反向资金或客户欠款、写审计与 outbox。
3. 现结销售从原收款账户退回原销售总额；账户余额不足时拒绝冲销，不允许形成未经批准的负资金。
4. 未收款赊账销售将原应收标记为 `REVERSED` 且未结金额归零。
5. 已发生任何销售退货的原单禁止整单冲销；已发生客户收款核销的赊账原单也禁止直接冲销，必须先实现并完成收款反核销。
6. 冲销要求原因、业务日期、精确时间、操作者和幂等键。重复请求不得产生第二次账务影响。

## 备选方案

- 直接修改或删除原单：拒绝，无法保持审计和账本可重建性。
- 把所有错单都当销售退货：拒绝，混淆真实退货与记账错误。
- 首版自动拆解已退货、已收款的复杂单据：暂缓，需要跨退货、收款和反核销模块定义更完整的依赖顺序。

## 后果

- 普通未派生后续业务的错单可以安全、可追溯地一键冲销。
- 已退货或已收款单据需要先处理其后续单据，操作步骤更多，但避免重复退款、重复回库和应收错乱。
- 后续实现收款反核销时，必须继续遵守来源单据、不可变反向记录和幂等事务规则。
