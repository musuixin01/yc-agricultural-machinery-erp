# ADR-0004：客户收款按整单反核销

- 状态：已接受
- 日期：2026-08-31

## 背景

客户收款会同时增加资金并减少一笔或多笔客户欠款。直接删除收款、修改核销关系或手工增加欠款会破坏账本可追溯性。销售错单在已经收款后也不能安全冲销，必须先撤销这笔收款影响。

## 决策

1. 采用独立 `CustomerReceiptReversal` 反向单据，引用唯一原收款单；原收款与原核销关系永久保留。
2. 首版只允许整张原收款单反核销，不提供部分反核销。反向单据逐项引用原核销关系，恢复相同客户欠款，并从原收款账户减少原收款总额。
3. 反核销在一个 Serializable 事务内完成，包含反向单据、恢复应收、反向资金流水、资金余额、审计、幂等和 outbox。
4. 原资金账户余额不足时拒绝反核销，不允许形成未经授权的负资金。
5. 任一相关销售单已发生销售退货时拒绝反核销，因为退货的欠款冲减与退款拆分依赖当时的收款状态；必须先处理下游退货关系。
6. 已完成反核销的收款不再阻止对应销售单冲销；未反核销的有效收款仍然阻止销售冲销。

## 备选方案

- 删除原收款或原核销关系：拒绝，无法保留正式账务历史。
- 允许任意部分反核销：暂缓，会产生剩余收款、拆分核销和多次反向关系，首版复杂度与误操作风险较高。
- 发生退货后自动重算并反核销：暂缓，需要同时重排退货退款和应收冲减，容易重复退款。

## 后果

- 普通收款错录可以安全更正，客户欠款和资金恢复到收款前状态。
- 已收款赊账错单可以先反核销，再执行销售单冲销。
- 涉及后续销售退货的收款需要更完整的下游单据撤销流程，当前会明确拦截。
