# ADR-0002：AC 响应式 UI 方向

- 状态：已接受
- 日期：2026-08-12

## 背景

UI 原型提供 A「田野中枢」、B「账本工作台」、C「移动门店」三种信息架构。实际使用同时要求店内 Windows 电脑具备高信息密度与键盘效率，手机具备清晰触控、扫码和欠款跟进路径。

## 决策

- 宽度大于等于 761 CSS 像素采用 A 的桌面侧栏、经营看板、表格与快捷业务结构。
- 宽度小于 761 CSS 像素采用 C 的移动首页、底部导航、大触控目标和扫码入口。
- 两端共享当前业务页面和 URL，不要求用户手工选择界面模式。
- 动效使用 `transform`、`opacity` 和原生 View Transitions 渐进增强；不支持时正常即时切换。
- 尊重 `prefers-reduced-motion`，减少动态效果时关闭非必要动画。

## 理由

A 更符合店内电脑的连续开单、库存表格和多模块切换；C 更符合手机单手操作和快速业务入口。按设备宽度组合可保留两者优势，同时避免维护两套业务语义。

## 后果

正式组件需要共享领域状态与 API 契约，但允许桌面和移动使用不同布局组件。每个关键页面必须同时验证桌面与 390×844 手机视口；响应式切换不得丢失当前页面或未保存输入。
