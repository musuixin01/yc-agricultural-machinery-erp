# ADR-0005：供应商付款按整单反核销

- 状态：已接受
- 日期：2026-08-31

## 背景

供应商付款会同时减少资金和一笔或多笔供应商欠款。直接删除付款、修改核销关系或手工增加应付会破坏资金与应付账本的可追溯性，而部分反核销会引入剩余付款、多次反向关系和更高的误操作风险。

## 决策

采用独立 `SupplierPaymentReversal` 反向单据引用唯一原付款单，首版只允许整单反核销。原付款及核销关系永久保留；一个 Serializable 事务逐项恢复原核销的应付、向原资金账户追加等额正向流水、把原付款标记为已反核销，并同步写入审计、幂等结果和 outbox。

供应商真实退回资金应使用未来的“供应商退款”业务，采购货物退回应使用“采购退货”，两者都不得借用付款反核销。未来增加采购退货后，必须检查其是否依赖原付款状态，必要时阻止反核销或先撤销下游单据。

## 后果

普通付款错录可以恢复到付款前的应付和资金状态；部分付款按任意顺序反核销时，应付状态由恢复后的未结金额重新计算。首版不支持部分反核销，也不把真实退款伪装成账务纠错。
