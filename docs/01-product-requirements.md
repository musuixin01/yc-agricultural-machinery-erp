# 产品需求说明（PRD）

## 1. 核心业务对象

- 商品：整机、配件、标准件/螺丝、服务项目。
- 往来单位：客户、供应商；同一单位可同时具备两种身份。
- 仓库与库位：保存可售、占用、在途等数量。
- 单据：采购、销售、退货、盘点、调拨、收付款和费用。
- 往来账：应收、应付、核销、账龄、信用额度。
- 资金账户：现金、银行卡、微信、支付宝等，系统仅记录业务流水。

## 2. 商品管理

### 必须支持

- 系统编码、名称、助记码、分类、品牌、型号、规格、主单位、状态；
- 一个商品多个条码，扫码枪按键盘输入即可使用；
- 采购单位与销售单位换算，如“1 箱 = 100 个”；
- 螺丝按直径、长度、牙距、材质、强度等级等规格筛选；
- 配件记录适配品牌/机型/备注，整机可记录序列号；
- 最低库存、默认采购价、零售价、批发价和最低售价权限控制；
- 图片/附件不直接塞入数据库大字段，保存对象存储路径和元数据；
- 停用商品不可新增业务，但历史单据仍可查询。

### 业务规则

- 商品编码、条码在有效范围内唯一；
- 单位换算一经产生业务不得直接改变影响历史，需新增版本或新商品；
- 价格只是默认值，最终成交价保存在单据明细中；
- 金额、单价、折扣都按明确精度和舍入规则计算。

## 3. 采购与应付

- 创建采购草稿，选择供应商、仓库、商品、数量、单价和预计到货日；
- 到货可一次或多次入库；允许在授权下直接创建采购入库单；
- 入库过账后增加库存、形成应付或现金付款记录；
- 采购退货减少库存并冲减应付，数量不足时禁止退货；
- 可登记付款并按指定单据核销，也可作为预付款保留；
- 展示供应商余额、未核销单据、账龄和交易明细。

## 4. 销售与应收

- 快速检索/扫码选品，显示可用库存、售价、客户历史价（需授权）；
- 支持现销、赊销、部分收款、多种支付方式组合；
- 销售过账后减少库存并产生收入与应收；
- 默认禁止负库存，低于最低售价或超信用额度时按权限警告/拦截；
- 销售退货回库并冲减应收或形成退款；
- 收款可指定核销销售单，也可形成预收款；
- 打印/导出销售单和客户对账单。

## 5. 库存

- 实时库存、可用库存、库存金额、收发存台账；
- 采购入库、销售出库、退货、盘点、调拨、报损报溢分别记账；
- 盘点采用“盘点任务 → 录入实盘 → 差异复核 → 过账”；
- 每一条库存流水必须包含商品、仓库、数量、成本、来源单据、时间；
- 库存余额可由不可变流水汇总核对，余额表只作为受控快照；
- 支持安全库存和滞销库存提示。

## 6. 往来账与资金

- 应收 = 客户已过账销售/调整 - 已核销收款/退货；
- 应付 = 已过账采购/调整 - 已核销付款/退货；
- 收付款必须有日期、金额、账户、往来单位、经办人和凭证附件（可选）；
- 支持预收、预付、部分核销、一笔款核销多单、多笔款核销一单；
- 账龄默认分为 0–30、31–60、61–90、90 天以上，可配置；
- 不允许直接编辑余额；更正必须通过反向/调整业务并留下原因；
- 经营费用与其他收入不自动冒充应收应付；资金账户间转账成对记录。

## 7. 报表与提醒

- 今日/本月销售、毛利、收款、付款、应收、应付和库存金额；
- 商品销售排行、低库存、滞销、库存收发存；
- 客户/供应商对账单、账龄、逾期和信用额度使用；
- 按商品、客户、供应商、经办人、日期筛选与导出；
- 所有报表显示口径、筛选条件、生成时间和币种；
- 看板不得直接从客户端拼接多个口径不一致的列表求和。

## 8. 非功能需求

- 可用性：在商户常用网络环境下，核心 API 月度可用性目标 99.5%。
- 性能：常用列表首屏 P95 小于 2 秒；过账 P95 小于 3 秒（不含打印）。
- 容量基线：10 用户、5 万商品、100 万单据明细；压测后再调整。
- 兼容：Windows 10/11，Android 10+；iOS 版本按发布计划确定。
- 安全：HTTPS、最小权限、密码安全存储、令牌轮换、敏感操作二次确认。
- 可维护：模块边界明确、自动迁移、结构化日志、指标、健康检查和测试。
- 可访问：不只用颜色表达状态；触控目标、字号、对比度满足常见可访问性准则。

## 9. 数据导入

导入流程固定为“下载模板 → 本地填报 → 预校验 → 显示错误 → 预览 → 确认导入 → 结果报告”。禁止直接把未知格式 Excel 写入正式表。期初库存、应收和应付必须使用专用期初单据，并在上线确认后锁定。

## 10. 验收场景

至少覆盖：现购、赊购、现销、赊销、部分收付款、预收预付、销售/采购退货、盘盈盘亏、调拨、作废/冲销、月结后调整、条码重复、并发销售最后一件商品、断网重试和重复提交。
