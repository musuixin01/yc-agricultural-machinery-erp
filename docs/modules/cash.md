# 资金账户与账户转账模块

## 业务边界

资金账户记录门店现金、银行卡、微信、支付宝等实际可用资金。账户间转账只改变资金存放位置，不形成收入、费用、应收或应付，也不改变全部账户资金总额。

## 已实现范围

- 在供应商结算工作台直接发起账户转账，桌面端与手机端共用同一正式接口。
- 只能在两个不同且启用中的账户之间转账，转出余额不足时拒绝整笔操作。
- 服务端按账户 ID 固定顺序加锁，在一个 Serializable 事务中建立转账单、转出/转入两条资金流水、更新两个余额、写审计和 outbox。
- 相同 `Idempotency-Key` 和相同内容重试返回原转账；相同键用于不同内容时拒绝。
- 正式转账单和资金流水不可直接更新或删除。

## API

- `GET /api/v1/cash/transfers`，要求 `cash.read`。
- `POST /api/v1/cash/transfers`，要求 `cash.post` 和 12–100 位 `Idempotency-Key`。

## 正式转账不变量

1. 转出与转入账户不能相同，必须启用并已建立余额。
2. 金额使用 `numeric(19,4)`，必须大于零且不得超过事务锁定后的转出余额。
3. 转出流水金额等于负的转账金额，转入流水金额等于正的转账金额，两条流水之和必须为零。
4. 转账单、两条流水、两个余额、审计和 outbox 必须全部成功或全部失败。
5. 正式记录不可改写；当前未实现转账冲销，禁止通过删除或手工改余额纠错。

## 验证

`apps/api/scripts/verify-cash-transfers.ts` 只允许连接名称包含 `_cash_transfer_verify` 的隔离数据库，验证正常转账、幂等重试、幂等键复用拦截、同账户拦截、余额不足回滚、成对流水净额为零以及数据库不可变约束。
