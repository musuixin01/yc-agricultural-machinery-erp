# 门店资料与系统参数模块

## 已实现范围

- 使用 PostgreSQL 单例 `business_profiles/primary` 保存正式门店名称、简称、联系电话、地址、票据说明和默认打印尺寸。
- 初始值只包含已确认的“玉春农机 / YC”；电话、地址和自定义说明默认留空，禁止把演示内容带入客户票据。
- 经营者可在“系统设置 → 门店资料”维护资料，保存后销售单预览、打印和图片立即读取新配置。
- 默认打印尺寸支持 `A4` 与 `80mm 小票`，每次打印前仍可临时切换，不会修改门店默认值。
- 更新使用 `version` 乐观并发控制，并在同一事务写入操作审计；旧设备不能静默覆盖新资料。

## API 与权限

- `GET /api/v1/administration/business-profile`：要求 `sales.read`，用于正式销售凭证。
- `PATCH /api/v1/administration/business-profile`：要求 `administration.manage`，首版只授予经营者。

修改接口不接受任意设置键，只接受明确建模和验证的门店字段，避免形成无约束 JSON 配置垃圾箱。

## 尚未实现与现场事项

- 门店 Logo、印章、收款二维码、税号和多门店独立抬头尚未实现。
- 电话、地址由经营者自行确认；系统不做真实性认证。
- A4 和 80mm HTML 已通过 Chromium 打印渲染，但实际 Windows 打印驱动、热敏纸边距、切刀和中文字体仍需用目标打印机现场验收。
